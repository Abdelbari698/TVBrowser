📺 Mon Launcher TV — Guide complet

Comment compiler et installer l'APK sur ta Android TV

1 Télécharger Android Studio

C'est l'outil gratuit de Google pour créer des apps Android. C'est le seul logiciel dont tu as besoin.

  • Va sur : https://developer.android.com/studio
  • Clique sur "Download Android Studio"
  • Installe-le normalement (suivre les étapes par défaut)
    • 💡 Android Studio pèse environ 1 Go — prends le temps qu'il faut

    2 Créer le projet

    Ouvre Android Studio, puis :

  • Clique sur "New Project"
  • Choisis "Empty Views Activity"
  • Nom du projet : TVBrowser
  • Package name : com.monlauncher.tvbrowser
  • Language : Java
  • Minimum SDK : API 21 (Android 5.0)
  • Clique Finish

    • 3 Copier les fichiers du projet

    Remplace les fichiers existants par les fichiers fournis. Voici la structure :

    TVBrowser/
    ├── app/src/main/
    │ ├── AndroidManifest.xml ← remplacer
    │ ├── java/com/monlauncher/tvbrowser/
    │ │ └── MainActivity.java ← remplacer
    │ ├── res/layout/
    │ │ └── activity_main.xml ← remplacer
    │ ├── res/values/
    │ │ └── styles.xml ← remplacer
    │ └── assets/ ← créer ce dossier
    │ └── index.html ← ajouter
    ├── build.gradle ← remplacer
    └── settings.gradle ← remplacer
    ⚠️ Pour créer le dossier assets : clic droit sur main/ → New → Directory → tape assets

    4 Compiler l'APK

  • Dans Android Studio, menu Build → Build Bundle(s) / APK(s) → Build APK(s)
  • Attends la fin de la compilation (2-5 minutes)
  • Clique sur "locate" dans la notification en bas
  • L'APK se trouve dans : app/build/outputs/apk/debug/app-debug.apk
    • 💡 L'APK pèse environ 3-5 Mo — très léger !

    5 Installer l'APK sur la TV

    Il y a deux méthodes :

    Méthode A — Clé USB

  • Copie l'APK sur une clé USB
  • Branche la clé sur la TV
  • Ouvre le gestionnaire de fichiers de la TV
  • Navigue jusqu'à l'APK et clique dessus pour installer

    • Méthode B — ADB Wi-Fi (plus rapide)

  • Sur la TV : Paramètres → À propos → clique 7 fois sur Build pour activer les options développeur
  • Paramètres développeur → Active "ADB sur réseau" → note l'IP (ex: 192.168.1.50)
  • Sur PC dans un terminal : adb connect 192.168.1.50:5555
  • Puis : adb install app-debug.apk

    • 6 Utiliser le launcher

  • Renomme ton fichier HTML en launcher.html
  • Copie-le sur une clé USB
  • Branche la clé USB sur la TV
  • Ouvre l'app "Mon Launcher TV"
  • L'app trouve automatiquement le fichier et l'affiche ✅
    • 💡 Si l'app ne trouve pas le fichier, elle affiche une page d'aide avec les instructions
